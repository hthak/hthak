## Featured Projects

### Ischemic Episode Detection
Machine learning system for detecting ischemic ST episodes from long-term ECG recordings using physiological features, Random Forest models, and a 1D CNN.

### MenuMatch
AI powered dining nutrition system that identifies foods and estimates portion sizes from meal images using computer vision, CLIP, LLMs, and geometric volume estimation.

### OCT Retinal Disease Classification
Medical image classification project using classical machine learning, feature engineering, ensemble methods, and convolutional neural networks to classify retinal OCT scans.

### Serverless Auction Platform
Full-stack auction application built with React and AWS using API Gateway, Lambda, Step Functions, DynamoDB, SNS, and SQS.
